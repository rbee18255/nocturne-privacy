Nocturne

Privacy Policy

Effective date: August 9, 2026

Nocturne does not collect, transmit, sell, or share any of your data. It has no server, no analytics, and no network calls of any kind. Everything it does happens entirely inside your own browser.

What data Nocturne stores, and where

Nocturne saves a small set of preferences so it can remember how you like your screen to look:

SettingExample valuePurpose
Enabled / disabledtrueWhether the effect is currently on
Mode"auto" or "manual"Automatic day curve vs. your own settings
Manual warmth3400 (Kelvin)Your chosen color temperature, if in manual mode
Manual brightness0.9Your chosen brightness, if in manual mode
Effect strength0.65How strong the overall effect is

These are stored using Chrome's built-in storage.sync API, which means:

The data is saved locally in your browser profile. If you're signed into Chrome, this small settings object may be synced by Google across your own signed-in devices — the same as your bookmarks or browser preferences — but Nocturne itself never sends it anywhere. Nocturne has no backend server and cannot access this data itself. No one, including us, can see your settings.

Nocturne does not collect: your browsing history, page content, keystrokes, personal information, location, health information, financial information, or any other identifiable data. It does not use cookies, trackers, or analytics of any kind.

Why Nocturne requests the permissions it does

PermissionWhat it's for
StorageSaving your warmth/brightness/mode preferences (see table above)
AlarmsRefreshing the toolbar badge icon once a minute so it reflects the current time of day
Host permissions (all sites)Applying the color/brightness filter to whichever page you're viewing. Nocturne only changes the visual rendering of the page — it does not read, log, or transmit page content anywhere

Third parties

Nocturne does not integrate with, or share data with, any third-party service, advertiser, or analytics provider. There is nothing to opt out of, because nothing is ever sent out.

Children's privacy

Nocturne does not knowingly collect any information from anyone, including children, because it does not collect information at all.

Changes to this policy

If this policy ever changes — for example, if a future version adds a genuinely new feature that touches data handling — we'll update the effective date above and describe the change here.
